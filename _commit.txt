feat: 流光现代 UI 重做 + 开机自启

界面完全重做，从 Win11 文件管理器风格的灰白扁平改为 Fluent 流光风格。

UI 层
- 流光（Aurora）动态渐变背景：低分辨率逐像素计算色斑叠加后双线性放大，
  单帧约 4ms，可流畅 25fps 动画
- 半透明玻璃卡片（AlphaBlend 约 59% 不透明度），流光可真实透过
- 渐变胶囊主按钮、圆形图标按钮、iOS 风格开关、细滚动条
- 移除 ListView / Button / STATIC 等子控件，改为单窗口全自绘，
  从而能自由做圆角、玻璃层次与流光
- 自绘标题栏（最小化/关闭），DWM 圆角 + 标题栏配色
- 列表行改为「标题 + 进程名」两行布局，已置顶项加强调色竖条与图钉标记
- 跟随系统深/浅色主题

开机自启
- 新增 autostart.py：写 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，
  无需管理员权限
- 设置卡片内开关 + 托盘右键菜单项，两处状态同步
- 自启命令带 --tray 参数，登录后直接进托盘不弹窗
- 打包成 exe 与源码运行两种方式都能正确注册

代码结构
- ontop.py    主程序：窗口过程、窗口枚举/置顶、托盘、快捷键
- ui.py       界面层：布局、命中测试、控件绘制
- aurora.py   绘制引擎：流光、圆角/渐变/玻璃、文本
- theme.py    主题：调色板、字体、流光色斑
- autostart.py 开机自启

原有功能全部保留：窗口枚举、置顶/取消、全部取消、搜索过滤、
托盘常驻、Ctrl+Alt+T / Ctrl+Alt+M 快捷键、高 DPI 适配。
旧版 ListView 实现保留在 ontop_legacy_listview.py 供对照。
