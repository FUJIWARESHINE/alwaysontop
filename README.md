# 窗口置顶小工具（AlwaysOnTop）

一个 Win11 下的小工具，只做一件事：把任意窗口设为「始终在最前面」，
方便全屏打游戏时把浏览器浮在上面看视频。

界面视觉对齐 **「文件批量重命名」（FileRename）**：深色玻璃拟态 + 靛蓝/紫/青
径向辉光（流光），无边框自绘标题栏，**所有设置收进右上角三条杠菜单**。

全部用 GDI 逐像素自绘，**零第三方依赖**（连图标都是纯代码画的）。

## 用法
1. 双击 `dist/AlwaysOnTop.exe` 即可运行（单文件、无需安装、不依赖 Python）。
2. 在列表里选中目标窗口，点「置顶窗口」或**双击列表项**切换。
3. 点右上角 **☰** 打开设置菜单（见下）。
4. 工具栏还有「刷新」和「取消全部」；右侧搜索框可按标题/进程名过滤。

## 右上角三条杠菜单（所有设置都在这里）
| 菜单项 | 说明 |
| --- | --- |
| **开机自启** | 写入当前用户的 Run 键，登录后自动运行；**开机启动时直接收进托盘**，不弹主窗口 |
| **置顶后转入后台** | 一旦置顶某个窗口，程序立刻收进托盘，游戏画面不被挡住 |
| **浅色 / 深色主题** | 一键切换，初始值跟随系统 |
| **刷新列表** | 重新枚举所有可见窗口 |
| **取消全部置顶** | 一次性解除所有窗口的置顶 |
| **快捷键说明** | 在状态栏显示快捷键提示 |
| **收进托盘运行** | 隐藏主窗口，继续在托盘常驻 |
| **退出** | 真正退出程序 |

前两项是开关，菜单不会关闭，方便连续切换。

## 托盘
程序常驻系统托盘，**托盘图标可见**（自绘的渐变图钉图标，不依赖外部图片文件）。

- 关掉主窗口（点 ✕）或点「收进托盘运行」，程序都会转入托盘，全局快捷键仍生效。
- **单击 / 双击托盘图标** → 重新打开主窗口。
- **右键托盘图标** → 菜单：打开主窗口 / 刷新 / 取消全部置顶 / 开机自启 / 退出。

## 快捷键
- **Ctrl + Alt + T**：随时切换「当前最前台窗口」的置顶状态。
- **Ctrl + Alt + M**：显示 / 隐藏主窗口。

## 开机自启细节
- 注册位置：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `AlwaysOnTopTool`，
  **不需要管理员权限**。
- 注册的命令带 `--tray` 参数，开机登录后**直接进托盘、不弹主窗口**，不打扰。
- 打包成 exe 后注册 exe 自身；用源码运行时注册 `pythonw.exe + ontop.py`，
  两种运行方式都能正确自启。

## 代码结构
| 文件 | 职责 |
| --- | --- |
| `ontop.py` | 主程序：窗口过程、消息处理、窗口枚举/置顶、托盘、快捷键、自截验证 |
| `ui.py` | 界面层：布局计算、命中测试、全部控件绘制、三条杠菜单 |
| `aurora.py` | 绘制引擎：画布与半透明合成、流光背景、圆角/渐变、文本 |
| `theme.py` | 设计令牌：深浅色调色板、字体、辉光配置 |
| `autostart.py` | 开机自启注册表读写 |
| `appicon.py` | 应用图标（纯代码绘制，输出 HICON / .ico / .png） |
| `gen_icon.py` | 生成 `icon.ico` / `icon.png` |

### 实现上有三个坑值得记一笔
1. **半透明合成不用 `AlphaBlend`。** 实测该函数在部分会话/环境（无真实显示适配器、
   受限窗口站）下会**静默返回失败**，导致玻璃面板整个消失。这里改为「逐通道 LUT +
   `bytes.translate`」在 C 层完成合成，速度更快且结果可逐像素验证。
2. **字体句柄必须声明 `restype`。** `CreateFontW` 返回 64 位 HFONT，若不声明返回类型，
   ctypes 会按默认 `c_int` 截断，句柄失效后 `SelectObject` 静默失败 ——
   表现就是图标字体整片消失、中文回退成宋体。
3. **GDI 的家族名是 `Segoe UI Variable Text`。** 裸的 `Segoe UI Variable`
   （DirectWrite 的写法）GDI 找不到，会静默回退。

### 流光背景怎么做的
三团径向辉光（靛蓝 / 紫 / 青，对齐 FileRename 的 `body::before`）在
56×38 的低分辨率缓冲上逐像素计算，再用 `StretchBlt` 双线性放大铺满窗口 ——
模糊由放大天然完成，比在高分辨率上做高斯快两个数量级，单帧约 4ms。

## 开发者：自截验证
GUI 程序在受限会话里无法用外部截图工具抓窗口，程序内置了自截模式
（在窗口所属进程内 `BitBlt` 自己的客户区）：

```bash
python ontop.py --shot out.png     # 渲染主界面并存图后退出
```

## 重要前提（必读）
- **独占全屏（exclusive fullscreen）** 游戏会独占整个显示输出，置顶窗口也会被盖住。
  请改用 **无边框全屏 / 窗口化全屏**（现在绝大多数游戏都支持），置顶才生效。
  这是 Windows 显示机制的硬限制，不是 bug。
