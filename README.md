# 窗口置顶小工具（AlwaysOnTop）

一个 Win11 下的小工具，只做一件事：把任意窗口设为「始终在最前面」，
方便全屏打游戏时把浏览器浮在上面看视频。

界面采用 **Fluent 流光（Aurora）风格**：多色光斑缓慢漂移的动态渐变背景，
叠加半透明玻璃卡片、圆角胶囊按钮与随系统明暗切换的配色。
全部用 GDI 逐像素自绘，**零第三方依赖**（图标生成可选 Pillow）。

## 用法
1. 双击 `dist/置顶小工具.exe` 即可运行（单文件、无需安装、不依赖 Python）。
2. 在列表里选中目标窗口（带图钉标记表示已置顶），点「置顶窗口」或**双击列表项**切换。
3. 图标按钮：「↻」重新枚举窗口，「🗑」一键解除所有窗口的置顶。
4. 右上角搜索框可按标题/进程名过滤。
5. 「置顶后转入后台」开关：开启后，一旦点了「置顶」，程序就**自动最小化到系统托盘**——
   游戏画面不再被工具窗口挡住。
6. 需要重新打开主窗口：**Ctrl + Alt + M**，或单击/双击托盘图标；托盘右键菜单可
   「刷新 / 取消全部置顶 / 开机自启 / 退出」。

## 开机自启
界面「设置」卡片里的 **「开机自启」** 开关，或托盘右键菜单同名项。

- 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，**不需要管理员权限**。
- 注册的命令带 `--tray` 参数，开机登录后**直接进托盘、不弹主窗口**，不打扰。
- 打包成 exe 后注册的是 exe 自身；用源码运行时注册 `pythonw.exe + ontop.py`，
  因此两种运行方式都能正确自启。

## 后台运行（托盘）
- 关掉主窗口（点 ×）或点「置顶后转入后台」，程序都会转入**系统托盘**常驻，
  全局快捷键仍然生效。
- 真正退出请用托盘图标右键 →「退出」。

## 快捷键
- **Ctrl + Alt + T**：随时切换「当前最前台窗口」的置顶状态。
- **Ctrl + Alt + M**：显示 / 隐藏主窗口。

## 代码结构
| 文件 | 职责 |
| --- | --- |
| `ontop.py` | 主程序：窗口过程、消息处理、窗口枚举/置顶、托盘、快捷键 |
| `ui.py` | 界面层：布局计算、命中测试、全部控件绘制 |
| `aurora.py` | 绘制引擎：流光背景、圆角/渐变/半透明玻璃、文本绘制 |
| `theme.py` | 主题：深浅色调色板、字体、流光色斑配置 |
| `autostart.py` | 开机自启注册表读写 |

渲染架构上有两点值得说明：

- **流光背景**在 56×38 的低分辨率缓冲上用 smoothstep 衰减的色斑叠加逐像素计算，
  再由 `StretchBlt` 双线性放大到窗口。低分辨率 + 放大 = 天然柔化，
  比在高分辨率上做模糊快两个数量级，单帧约 4 ms，足够 25fps 流畅播放。
- **玻璃卡片**先在临时 DC 上画实色圆角，再用 `AlphaBlend` 以约 59% 不透明度
  叠到背景上，因此流光能真实地透过卡片。

## 重要前提（必读）
- **独占全屏（exclusive fullscreen）** 游戏会独占整个显示输出，置顶窗口也会被盖住。
  请改用 **无边框全屏 / 窗口化全屏**（现在绝大多数游戏都支持），置顶才生效。
  这是 Windows 显示机制的硬限制，不是 bug。
